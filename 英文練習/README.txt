海格堡三年級英文複習遊戲｜教材匯入版

開啟方式：解壓縮後執行「啟動網站-Windows.bat」（電腦需安裝 Python），瀏覽 http://localhost:8000。
若已經有其他本機網站占用 8000，請先關閉。
教材：14 章、142 筆原始記錄；相同英文合併學習統計，但保留全部來源章節及原文。
題目自動生成，句型問答採經過配對的教材原句；自然發音干擾詞可超出教材。
重要：發音採線上字典 API，無法取得時使用瀏覽器 en-US 語音，尚非逐筆審核之正式音檔。
網頁尚未部署至公網。localhost 是電腦本機網址，外部裝置無法直接使用。
學習紀錄存在本機 localStorage。題庫寶典可匯入／匯出 JSON 備份。
